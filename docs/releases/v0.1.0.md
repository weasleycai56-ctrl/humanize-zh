# Humanize ZH v0.1.0 — release notes draft

> Draft for maintainer review. Verify the tagged commit before publishing.

## What this release is

Humanize ZH is an explainable Chinese writing-style linter and rewriting Skill. The first release focuses on Chinese-specific editing problems instead of translating an English “AI word list.” It diagnoses observable patterns and supports light or strong revision while preserving facts, citations, uncertainty, and regional language.

## Highlights

- Three modes: audit only, light edit, strong rewrite.
- Five contexts: casual, professional, academic, social, marketing.
- Fourteen documented signal categories, each with an editorial rationale and legitimate-use boundary.
- Explainable diagnostics with issue type, source excerpt, reason, and suggestion.
- A local, zero-dependency Python pre-linter for repeatable first-pass audits.
- Ten before/after fixtures covering all supported contexts.
- Explicit refusal to claim AI-authorship detection or detector bypass.

## Install

```bash
cp -R humanize-zh ~/.codex/skills/humanize-zh
```

Then try:

```text
Use $humanize-zh in audit mode on the following Chinese text. Diagnose only; do not rewrite.
```

## Known limitations

The deterministic linter is intentionally conservative and cannot understand every context. Style findings are not evidence of AI authorship. Literary writing, dialect, historical Chinese, dialogue, and regulated templates need further evaluation.
